## 進位字串 ⮕ int

```python
進位字串 = '10'
print(int(進位字串, 2)) # 2
print(int(進位字串, 8)) # 8
print(int(進位字串, 10)) # 10
print(int(進位字串, 16)) # 16
```

## 進位字串 ⮕ bytes

```python
s = "0100000101000010"
bytes_big = int(s, 2).to_bytes((len(s) + 7) // 8, byteorder="big")
bytes_little = int(s, 2).to_bytes((len(s) + 7) // 8, byteorder="little")

print(bytes_big) # b'AB'
print(bytes_little) # b'BA'
```

## format

用來將數值或文字，依指定格式轉成字串


### 寫法

| 寫法               | 範例                   | 回傳結果     |
| ---------------- | -------------------- | -------- |
| 內建函式 `format()`  | `format(x, ".2f")`   | `"3.14"` |
| 字串方法 `.format()` | `"{:.2f}".format(x)` | `"3.14"` |
| f-string         | `f"{x:.2f}"`         | `"3.14"` |

### 字串方法 `.format()`

**使用 `.format()` 時，`{}` 決定資料放在哪裡。** 可以依序填入、指定位置，或使用名稱。

#### 依序填入

```python
"姓名：{}, 年齡：{}".format('sherlock', 20)
# 姓名：sherlock, 年齡：20
```

#### 指定位置，從 0 開始

```python
"年齡：{1}，姓名：{0}".format('sherlock', 20)
# 年齡：20，姓名：sherlock

"{0} + {0} = {1}".format('1' , '2')
# 1 + 1 = 2
```

#### 使用名稱

```python
"姓名:{name} , 年齡：{age}".format(name="sherlock", age=20)
# 姓名:sherlock , 年齡：20
```

#### 取出 List 或 Dict 元素

**List**

```python
names = ['conan', 'sherlock', 'darkrai']
s = 'n1 : {0[0]} , n2 : {0[1]} , n3 : {0[2]}'.format(names)
print(s)

# n1 : conan , n2 : sherlock , n3 : darkrai
```

**Dict**

```python
data = {
    'name' : 'marin',
    'age' : 17
}

s = '{0[name]}:{0[age]}'.format(data)
print(s)

# marin:17
```

或

```python
data = {
    'name' : 'marin',
    'age' : 17
}

s = '{name}:{age}'.format(**data)
print(s)

# marin:17
```

### 規格

```python
format(值, "格式規格")

"{欄位:格式規格}".format(...)

f"{值或運算式:格式規格}"
```

```js
format(12345.6, "*>+14,.2f")

*   >   +   14   ,   .2   f
│   │   │   │    │    │   └─ 類型
│   │   │   │    │    └──── 精度
│   │   │   │    └───────── 分隔符
│   │   │   └────────────── 寬度
│   │   └────────────────── 正負號
│   └────────────────────── 對齊
└────────────────────────── 填補字元


[[填補字元]對齊][正負號][#][0][寬度][分隔符][.精度][類型]
```

|  順序 | 格式部分 | 可用值               | 說明                    | 範例                                          |
| --: | ---- | ----------------- | --------------------- | ------------------------------------------- |
|   1 | 填補字元 | 任意單一字元            | 空位要使用什麼字元填補；必須與對齊一起使用 | `format("abc", "*^9")` <br>→ `'***abc***'`  |
|   2 | 對齊   | `<`、`>`、`^`、`=`   | 控制內容在指定寬度中的位置         | `format("abc", ">6")` <br>→ `' abc'`        |
|   3 | 正負號  | `+`、`-`、空格        | 控制正數及負數的符號顯示          | `format(42, "+d")` <br>→ `'+42'`            |
|   4 | 替代格式 | `#`               | 顯示進位前綴，或強制浮點數保留小數點    | `format(10, "#b")` <br>→ `'0b1010'`         |
|   5 | 補零   | `0`               | 數值寬度不足時補 `0`          | `format(42, "05d")` <br>→ `'00042'`         |
|   6 | 寬度   | 正整數               | 指定輸出的最小總寬度            | `format(42, "6d")` <br>→ `' 42'`            |
|   7 | 分隔符  | `,`、`_`           | 對大數加入千分位或底線分隔         | `format(1234567, ",d")` <br>→ `'1,234,567'` |
|   8 | 精度   | `.` 加整數           | 控制小數位數、有效位數或字串最大長度    | `format(3.14159, ".2f")` <br>→ `'3.14'`     |
|   9 | 類型   | `b`、`d`、`f`、`x` 等 | 指定二進位、十進位、浮點數等表示方式    | `format(10, "08b")` <br>→ `'00001010'`      |
