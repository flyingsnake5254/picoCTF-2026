## 符號式與方程式

| 用途        | 建立方式                          | 適合操作                          |
| --------- | ----------------------------- | ----------------------------- |
| 符號運算 `SR` | `x = var("x")`                | 解方程、三角函數、根號、微積分               |
| 多項式環      | `R = PolynomialRing(QQ, "x")` | 因式分解、求根、GCD、除法、Groebner basis |


### 建立符號變數

```python
from sage.all import *

x = var("x")
y = var("y")
```

也可以一次建立：
```python
from sage.all import *

x, y, z = var("x y z")
```

### 建立多項式

```python
expr = x**2 + 5*x + 12
print(expr)
```

輸出：
```bash
x^2 + 5*x + 12
```


### 展開多項式 - expand()

```python
expr = (x + 3)*(x - 2)
print(expr.expand())
```

輸出：
```bash
x^2 + x - 6
```

### 因式分解多項式 - factor()

```python
expr = x**2 + x - 6
print(expr.factor())
```

輸出：
```bash
(x + 3)*(x - 2)
```

### 代入數值 - subs()

```python
x, y = var("x y")
expr = x**2 + 2*x*y + y**2
print(expr.subs(x=5, y=3))
```

也可以使用字典：
```python
x, y = var("x y")
expr = x**2 + 2*x*y + y**2
value = {
    x: 5,
    y: 3
}
print(expr.subs(value))
```

輸出：
```bash
64
```

### 解一元方程式 - solve(expr, x)

```python
from sage.all import *

x = var("x")
eq = (x**2 - 5*x + 6 == 0)
solution = solve(eq, x)
print(solution)
```

輸出（List）：
```bash
[
x == 3,
x == 2
]
```

取得答案數值：

用法：
```python
solutions[0].lhs()  # x
solutions[0].rhs()  # 3
```

範例：
```python
from sage.all import *

x = var("x")
eq = (x**2 - 5*x + 6)

solutions = solve(eq, x)
values = [s.rhs() for s in solutions]
print(values)
```

輸出（List）：
```css
[3, 2]
```


若要輸出字典型態的 Solution :
```python
from sage.all import *

x = var("x")
eq = (x**2 - 5*x + 6)
solutions = solve(eq, x, solution_dict=True)
print(solutions) # [{x: 3}, {x: 2}]
print(solutions[0][x]) # 3
```


### 解聯立方程式

```python
from sage.all import *

x, y = var("x y")

equations = [
    x + y == 7,
    2*x + y == 10
]

solutions = solve(
    equations,
    x, y,
    solution_dict=True
)

print(solutions)
```

輸出：
```json
[{x: 3, y: 4}]
```

### 解含參數的方程式

```python
from sage.all import *

x, a, b, c = var("x a b c")
equations = (a*x**2 + b*x + c == 0)
solutions = solve(
    equations,
    x,
    solution_dict=True
)
print(solutions)
```

輸出：
```json
[
	{x: -1/2*(b + sqrt(b^2 - 4*a*c))/a}, 
	{x: -1/2*(b - sqrt(b^2 - 4*a*c))/a}
]
```

### 不等式

```python
from sage.all import *

x = var("x")
result = solve(x**2 - 5*x + 6 > 0, x)
print(result)
```

輸出：
```json
[[x < 2], [x > 3]]
```

### 方程式區間數值解

如果方程式沒有方便的封閉形式，可以指定區間求數值解：
```python
from sage.all import *

x = var("x")

root = find_root(x**5 - x - 1 == 0, 1, 2)
print(root) # 1.1673039782615173
```


## 多項式環

### 建立一元多項式環

```python
from sage.all import *

R = PolynomialRing(QQ, "x") # 或是撿寫成：R = QQ["x"]
x = R.gen()

f = x**3 - 6*x**2 + 11*x - 6
print(f) # x^3 - 6*x^2 + 11*x - 6
```


**係數環的選擇**
```python
PolynomialRing(ZZ, "x")       # 整數係數
PolynomialRing(QQ, "x")       # 有理數係數
PolynomialRing(RR, "x")       # 浮點實數係數
PolynomialRing(CC, "x")       # 浮點複數係數
PolynomialRing(GF(7), "x")    # 模 7 的有限體
```

|符號|意義|
|---|---|
|`ZZ`|整數環 (\mathbb Z)|
|`QQ`|有理數域 (\mathbb Q)|
|`RR`|浮點實數域|
|`CC`|浮點複數域|
|`AA`|精確實代數數域|
|`QQbar`|精確代數數閉包|
|`GF(p)`|有限體|

**分數係數**
```python
R = PolynomialRing(QQ, "x")
x = R.gen()

f = QQ(1)/3*x**2 + QQ(2)/5*x - 1
print(f)
```


使用以下程式為例：
```python
R = PolynomialRing(QQ, "x")
x = R.gen()

f = x**3 - 6*x**2 + 11*x - 6
```

### 取得所有係數 - list()

```python
f.list() # 結果由低次到高次排列：[-6, 11, -6, 1]
```

### 多項式最高次數 - degree()

```python
f.degree() # 3
```

### 取得指定次方係數

```python
f[3]  # x^3 的係數：1
f[2]  # x^2 的係數：-6
f[1]  # x 的係數：11
f[0]  # 常數：-6
```

### 首項係數 - leading_coefficient()

```python
f.leading_coefficient()   # 1
```

### 常數項係數 - constant_coefficient()

```python
f.constant_coefficient()  # -6
```

### 多項式因式分解 - factor()

```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

f = x**3 - 6*x**2 + 11*x - 6
print(f.factor()) # (x - 3) * (x - 2) * (x - 1)
```

### 檢查是否不可約 - is_irreducible()

```python
f.is_irreducible()
```

True : 不可約
False : 可約

### 多項式求根 - roots()

```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

f = x**3 - 6*x**2 + 11*x - 6
print(f.roots())
```

輸出：
```json
[(3, 1), (2, 1), (1, 1)]
```

每一項代表：
```json
(根, 重數)
```


**有重根的多項式**

```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

g = (x - 2)**3 * (x + 1)
print(g.roots())
```

輸出：
```json
[(-1, 1), (2, 3)]
```

若不想輸出重數，只輸出根（multiplicities=False）：
```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

g = (x - 2)**3 * (x + 1)
print(g.roots(multiplicities=False))
```

輸出：
```json
[-1, 2]
```


### 多項式微分

```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

f = x**3 - 6*x**2 + 11*x - 6
df = f.derivative() # 或 diff(f, x)
print(df) # 3*x^2 - 12*x + 11
```

### 多項式除法

```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

f = x**3 - 6*x**2 + 11*x - 6
divisor = x - 1
quotient, remainder = f.quo_rem(divisor)

'''
或是這樣寫：
quotient = f // divisor
remainder = f % divisor
'''

print("商：", quotient)
print("餘數：", remainder)
```

輸出：
```css
商： x^2 - 5*x + 6
餘數： 0
```

### 最大公因式 GCD

```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

f = (x - 1)*(x - 2)*(x - 3)
g = (x - 1)*(x + 5)

result = f.gcd(g)
print(result) # x - 1
```

### 多項式代數

```python
from sage.all import *

R = PolynomialRing(QQ, "x")
x = R.gen()

f = x**2 - 5*x + 6

print(f(2))  # 0
print(f(3))  # 0
print(f(10)) # 56
```

## 模數運算

### 計算整數餘數：%

```python
a = ZZ(38)

print(a % 7)    # 3
print(-2 % 7)   # 5
```

### 建立模 $n$ 的環：Zmod(n)

```python
R = Zmod(7)

a = R(10)       # 10 mod 7
b = R(5)

print(a)        # 3
print(a + b)    # 1，因為 3 + 5 = 8 ≡ 1 mod 7
print(a * b)    # 1，因為 3 × 5 = 15 ≡ 1 mod 7
print(a ** 4)   # 4
```

### 模反元素

在模 $n$ 下，$a^{-1}$ 滿足：
$$a\cdot a^{-1} \equiv 1 \pmod n$$

```python
R = Zmod(7)
a = R(3)

a_inv = a ** (-1)

print(a_inv)        # 5
print(a * a_inv)    # 1
```

其他寫法：

```python
print(a.inverse_of_unit())  # 5
print(inverse_mod(3, 7))    # 5
```

**只有與模數互質的元素才有反元素**

### 模除法

模除法其實是乘上反元素，例如：

```python
R = Zmod(7)

a = R(3)
b = R(5)

print(a / b)        # 2
```

因為

$$
\frac{3}{5}\equiv 3\cdot 5^{-1}\equiv 3\cdot 3\equiv 2\pmod 7
$$

### 模數元素轉回整數

```python
R = Zmod(7)
a = R(6)

print(a.lift())           # 6
print(a.lift_centered())  # -1
```

- `lift()`：通常回傳 $0,\dots,n-1$
- `lift_centered()`：回傳接近零的代表值

### 模次方、最大公因數、中國剩餘定理

```python
print(power_mod(3, 100, 7))   # 4

print(gcd(30, 18))            # 6

d, u, v = xgcd(30, 18)
print(d, u, v)
print(u * 30 + v * 18 == d)   # True
```

中國剩餘定理：

```python
x = crt(2, 3, 3, 5)

print(x)       # 8
print(x % 3)   # 2
print(x % 5)   # 3
```

表示求：  
```math
\begin{aligned}
x\equiv 2\pmod 3\\
x\equiv 3\pmod 5
\end{aligned}
```

### 解模方程式

```python
x = var("x")

solutions = solve_mod(4*x == 2, 6)
print(solutions)
# [(2,), (5,)]
```

多變數：
```python
x, y = var("x y")

solutions = solve_mod([
    2*x + y == 1,
    x - y == 3
], 5)

print(solutions)
# [(3, 0)]
```
