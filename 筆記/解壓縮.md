| 格式               | 解壓縮指令                                       |
| ---------------- | ------------------------------------------- |
| `.zip`           | `unzip archive.zip -d output/`              |
| `.7z`            | `7z x archive.7z -ooutput/`                 |
| `.rar`           | `unrar x archive.rar output/`               |
| `.tar`           | `tar -xf archive.tar -C output/`            |
| `.tar.gz`、`.tgz` | `tar -xzf archive.tar.gz -C output/`        |
| `.tar.bz2`       | `tar -xjf archive.tar.bz2 -C output/`       |
| `.tar.xz`        | `tar -xJf archive.tar.xz -C output/`        |
| `.tar.zst`       | `tar --zstd -xf archive.tar.zst -C output/` |
| `.gz`            | `gzip -dk file.gz`                          |
| `.bz2`           | `bzip2 -dk file.bz2`                        |
| `.xz`            | `xz -dk file.xz`                            |
| `.zst`           | `zstd -dk file.zst`                         |
| `.lz4`           | `lz4 -d file.lz4 output`                    |
| `.lzma`          | `xz --format=lzma -dk file.lzma`            |
| `.cab`           | `cabextract -d output/ archive.cab`         |
| `.cpio`          | `cd output && cpio -idmv < ../archive.cpio` |
